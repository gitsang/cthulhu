# 《无名祭祀书》 (Unaussprechlichen Kulten)

分类：禁忌典籍

阅读代价：中等至高度精神损伤；具体规则值依赖版本，需在补录时标注具体规则书版本与页码

## 别名/称号

- 《无法言说的崇拜》 (Nameless Cults — 英语版本名)
- 《冯·朱恩兹特秘书》 (Von Junzt's Book)

## 简介

《无名祭祀书》由德国神秘学者弗里德里希·威廉·冯·朱恩兹特 (Friedrich Wilhelm von Junzt) 撰写，于 1839 年在杜塞尔多夫出版，初版极少，随后遭到广泛查禁。作者在完稿次年以不明原因死亡，据说死前数月陷入极度恐惧，拒绝独处，最终被发现死在反锁的房间里——喉咙上留有未知动物的爪痕。

与《死灵之书》的古老性和《埃波恩之书》的实用性不同，《无名祭祀书》的特点是"调查式"：它是一部由旅行学者亲历记录的田野报告，描述了世界各地的秘密教团及其崇拜仪式。这使它成为了解现代（相对于神话古典时代）教团活动的最佳情报来源之一。

## 关键特征

- 作者：弗里德里希·威廉·冯·朱恩兹特，德国神秘学者、旅行家。
- 出版时间：1839 年，杜塞尔多夫首版；后有英语删减版（出版商为 Bridewall，节选了最不危险的部分）。
- 内容特点：田野调查风格，记录现实存在的教团活动与仪式，并附有作者的个人观察与危险警告。

## 获取方式

- 英语删减版流传相对较广，可在古书商和特定图书馆找到。
- 德语原版几乎不可见；据称每一本原版都伴随着某种形式的诅咒。
- 米斯卡塔尼克大学据传藏有一份德语原版的部分手稿复制件。

## 阅读代价

- 英语删减版：相对安全，但仍会触发对某些神祇的"被动感知"。
- 德语原版：完整版本涉及大量 A 级危险材料，阅读代价显著高于删减版。
- 特定章节：关于莎布·尼古拉斯和哈斯塔相关教团的部分被认为危险性最高。

## 关键知识点

- 世界各地主要神话教团的组织结构与招募方式。
- 多种仪式的粗略描述（出于学术谨慎，细节有所保留）。
- 教团活动地点的历史记录（部分已过时）。
