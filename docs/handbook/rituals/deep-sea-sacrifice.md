# 深海献祭仪式 (Deep Sea Sacrifice Ritual)

分类：仪式与法术

## 别名/称号

- 达贡献祭 (Dagon Offering)
- 海祭 (Sea Rite)

## 简介

深海献祭仪式是克苏鲁神话中与达贡崇拜和深潜者文明最直接关联的祭祀流程。它不是一次性的"召唤"，而是一种长期维系"人类社群与深潜者之间契约关系"的周期性仪式。在印斯茅斯等沿海社区，这种仪式已经维持了数代人，形成了稳定的宗教结构。

仪式的核心逻辑是交换：人类向深海献上祭品（最初是食物和金属，后来演变为人类本身），换取鱼群丰盛、风暴平息和"深海礼物"（金银珠宝与混血婚姻）。这种交换一旦开始，就极难终止——因为中断契约的后果由那些已与深潜者产生血缘关系的人来承担。

## 前置条件

- 材料：盐、鱼油、深海采集的矿石、血祭物（初期为动物，后期可能为人类）
- 时间：通常在涨潮时进行，新月或满月之夜效果更佳
- 场域：必须在海岸线附近，最好在有直接通往深海通道的礁石或码头
- 参与者：至少一名受过仪式传授的祭司，信众数量不限

## 执行流程

1. 净化仪式场域（用盐水清洗礼器与祭坛）
2. 诵读达贡崇拜的祈颂词（语言与深潜者语言有部分重叠）
3. 将祭品置于海水中，等待"被接受"的信号（通常为特定的水流变化或磷光出现）
4. 仪式负责人向深处发出特定频率的声音（或击打特制的击打乐器）
5. 等候深潜者使者从海中现身确认"协议续期"

## 失败后果

- 短期：祭品未被接受，可能触发深潜者对该社区的短期封锁（渔业失收）
- 中期：协议破裂，深潜者可能向社区发出直接警告（失踪、夜间骚扰）
- 长期：完全终止协议的代价通常由混血家庭成员承担——他们会"感受到召唤"，最终无法抗拒地走向海洋
