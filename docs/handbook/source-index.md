# Source Index

本文件用于统一登记 handbook 中“经典片段摘录 / 故事脉络 / 规则信息”的来源索引，确保可追溯与可审阅。

## 使用规则

- 每条可引用信息建议在本台账登记一个 `Source ID`。
- 条目正文可使用 `Source ID` 进行引用（例如：`来源：SRC-OT-001`）。
- 规则相关来源必须包含版本信息与章节/页码。
- 无法核验来源时，不得写为确定性事实；可标记“待考”。

## Evidence Levels

- A：原典可核验文本。
- B：权威二手资料（官方出版、成熟规则书、可靠研究）。
- C：社区归纳（仅补充，不覆盖 A/B）。
